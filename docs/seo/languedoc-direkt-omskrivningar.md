# Omskrivningar: Languedoc- och direkt-meningar

Underlag: `docs/seo/languedoc-direkt-meningar.md` (177 rader). **Nr** motsvarar radens ordning i den filen (rad 1 = första raden i tabellen).

Regler som tillämpats:
- Inga påståenden om att vinerna köps från Languedoc eller kommer "direkt" från producenten (undantag: sidan direktimport-vin, se nedan).
- Inga påståenden om "utan tillsatser" / "without additives".
- Ingen tidspress ("reservera innan pallen fylls").
- Inga prisjämförelser ("lägre pris", "bättre pris", "billigare än i butik", "better value").
- Inga sajtnamn i brödtext, eftersom samma text kan visas på båda sajterna.
- "(ta bort)" = ta bort meningen. Kontrollera att stycket fortfarande läser bra. Om ett stycke blir tomt, rapportera.
- "(oförändrad)" = behåll meningen som den är.
